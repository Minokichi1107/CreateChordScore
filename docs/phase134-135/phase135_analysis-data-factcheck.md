```

前半（long区間）の間隔中央値: 約0.84〜0.87秒（周期の約1.9〜2.0倍）

前半の間隔をそのまま2分割（中点補完）すると：

```
中点補完後の間隔: 中央値 0.425秒・標準偏差 0.008秒
BPM由来の周期:   0.440秒

過去記録では「真のbeat周期0.440秒に近い」とされていたが、
数値を並べると約3.4%の差があり、「非常に近い」とまでは言い切れない
細かさである（規則性自体は高い＝標準偏差は小さい、という点は
過去記録通り）。

### 「1拍おき」解釈の検証

**Fact（事実）**:
```
・前半のbeat間隔は後半の約1.9〜2.0倍
・遷移は1拍で急激に起きる（漸移ではない）
・前半のbeat間隔を2分割すると、標準偏差0.008秒という
  規則性の高いグリッドが得られる
・downbeat間隔・コード密度も、beatと近い比率（約2倍・約1.1倍）で
  区間により変化する
```

**Calculation（計算結果）**:
```
・中点補完グリッドの中央値0.425秒は、BPM由来の周期0.440秒と
  約3.4%の差がある
・downbeat間隔÷beat間隔は全区間で厳密に4
```

**Interpretation（解釈）**:
```
・「前半では実際の音楽的Beatの1拍おきしか検出されていない」という
  解釈は、上記Factと矛盾しない（中点補完の規則性の高さがこの解釈を
  支持する材料の一つにはなる）

・ただし別の解釈も排除できない。例えば「この楽曲が前半から後半に
  かけて、実際に（音楽的に）ハーフタイム・フィールからダブル
  タイム・フィールへ移行するような構成を持つ」可能性も、データ
  だけからは否定できない（バラードが後半に向けて熱量を増していく
  構成は珍しくない）。この場合、前半の間隔が「本来の半分しか
  検出されていない」のではなく、「前半は本当にゆったりした
  ビート感で書かれている（が、そのビート感の中でも実際にはもっと
  細かい拍が刻まれている）」というだけかもしれず、この2つの解釈は
  beat位置の数値だけからは区別できない
```

**Unknown（未確認）**:
```
・音源との照合（実際にどちらの拍が鳴っているか）は今回も未実施
・「1拍おきの検出漏れ」と「実際の音楽的なビート感の変化」の
  どちらであるかは、このJSONだけからは判定不能
```

**結論**: 「約2倍の間隔だから確実に1拍おきの検出である」とは
言えない。約2倍という数値自体と、その規則性の高さは確認できたが、
それが検出の問題なのか楽曲自体の構成なのかは、依然として
Interpretationの域を出ない。

## ⑥ 次の議論に残す論点（解決策は提案しない）

```
Beat Model関連:
  ・「約2倍の間隔変化」が音楽的な現象（ビート感の変化・構成の
    盛り上がり等）なのか、検出漏れなのかを、データ以外の手段
    （音源照合・他の検出ツールとの比較等）でどう見分けるか
  ・17曲中1曲だけがこの現象を示すという事実は、「稀だが実在する
    パターン」として今後どう扱うべきか（無視できない頻度なのか、
    外れ値として個別対応でよいのか）

Downbeat Model関連:
  ・「downbeatは常にbeatsの要素と完全一致する」という性質が、
    今回のサンプル（17曲）全件で100%成立した。これは偶然の
    一致なのか、ChordMini/madmomの検出方式に起因する構造的な
    性質なのか（前回整理した音楽理論的な3つの意味――構造・
    アクセント・聴感――のどれとも独立に、検出アルゴリズム側の
    実装上の制約である可能性も排除できない）

Measure Model関連:
  ・「downbeat間隔中のbeat数は常にtimeSignature.numeratorと一致する
    （4/4なら常に4）」という性質も17曲全件で例外なく成立した。
    これが一般的に成り立つ性質なのか、それとも単に今回のサンプルが
    たまたま素直な拍子の曲ばかりだったのか（6/8等の複合拍子の曲は
    今回のサンプルに含まれていない）

サンプルの範囲に関する論点:
  ・今回の17曲はいずれも単一のtimeSignature（すべて4/4）だった。
    拍子変更がある曲・複合拍子の曲での検証はまだ行っていない
  ・93baeafdのような区間分裂パターンが「稀な例外」なのか「もっと
    多くの曲に潜在するが今回のサンプルでは1曲しか引っかからな
    かった」のかは、17曲というサンプルサイズでは判断できない
```
