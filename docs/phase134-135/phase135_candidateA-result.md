## 1. Confirmed（確認できた事実）

```
・比較3曲すべてで、Beat Cursorは「一定に進む」という報告があった
・3曲とも「止まる→ジャンプ」のような違和感の報告は無かった
・（再掲・前回確認済み）93baeafd（瞳をとじて）については、
  以前の再生時に「止まったように見えてから大きく進む」という
  違和感が明確に報告されている
```

## 2. Unknown（まだ分からないこと）

```

  （前半0.42秒幅・後半0.22秒幅という計算上の差がそもそも本当に
  無かったのか、弱く存在したが気にならなかったのか、区別できない）
・"特に気になった時間帯"の報告が無いが、これが「該当箇所が無かった」
  のか「その項目自体は意識しなかった」のかは不明瞭
・93baeafdの観察（強い違和感）と、今回3曲の観察（一言・簡潔な確認）
  とでは、記述の詳しさ・注視の度合いに差がある可能性がある。
  この非対称性自体が結果の解釈に影響しうる点として記録しておく
```
