## 1. 前提として維持する選択済み方針
- 方式C: 音声終端まで完全に含まれるslot（スロット）だけを通常slotとして数える。
- C1: 末尾領域にchord onset（コード開始時刻）があれば診断し、チャート全体を既存方式へfallback（フォールバック）する。
- 不規則小節が1つでもあれば、新方式を部分適用せずチャート全体を既存方式へfallbackする。
- `raw.beats` と `raw.downbeats` を変更しない。
- 通常表示・編集表示・Section Layerはチャート単位の同一方式判定を共有する。
- 方式P（最終slotだけ部分幅にする）は共通slot幅の方針と両立しないため採用しない。

## 2. 境界生成契約

### 2.1 境界の分類
| 種別 | 意味 | 使用条件の状態 |
|---|---|---|
| `beat` | 入力`beats`に存在する実在拍時刻 | 入力検証を通過した値に限定する |
| `interpolated` | 隣接する実在拍間を`resolutionPerBeat`に基づき分割した境界 | 分割数・端点の重複除去・浮動小数点の扱いをテストで規定する必要あり |
| `extrapolated` | 最終実在拍より後ろに推定生成した境界 | 外挿許可条件と完全slot判定への使用可否が未決 |

境界種別は出所の記録であり、それ自体で境界の採用可否を決めない。

### 2.2 実装前に決める外挿の質問
| ID | 判断項目 | 選択肢・論点 | 推奨する次の扱い |
|---|---|---|---|
| BND-1 | 外挿を許可する根拠 | 直前1区間／複数区間の代表値／別の根拠 | 実曲測定と現行`buildSlotTimings()`の実装確認後に決める。現時点で数値を固定しない |
| BND-2 | 外挿できる区間数 | 1境界のみ／複数境界／必要なslot数まで | 無制限外挿は避ける候補。ただし上限は根拠なしに設定しない |
| BND-3 | 外挿境界を完全slotの終端に使えるか | 常に不可／条件付き可／常に可 | 常に可とはしない。条件付き可にするなら、その条件を明示する |
| BND-4 | 有効な間隔がない場合 | 診断＋fallback／新方式不適用／その他 | 正の有限間隔がない状態で固定0.5秒等を測定境界として扱わない |
| BND-5 | 最終小節の完全slot数が0 | 明示的な空状態／検証失敗／別扱い | 表現を先に定義し、負の幅・未定義indexを作らない |

### 2.3 最小限の境界不変条件
1. 採用する境界時刻は有限値である。
2. 境界列は厳密な時刻順であり、重複・逆行を許さない。
3. 各境界の出所を保持し、外挿境界を実在拍と同一視しない。
4. 外挿を完全slotの証拠にできる条件が満たされない場合、該当slotを黙って採用しない。
5. 音声終端をまたぐslotを部分幅で描画しない。
6. 末尾領域の幅が0なら空領域を生成しない。
7. `raw.beats`／`raw.downbeats`を変更しない。

## 3. 許容誤差契約
許容誤差は、単一の「タイミング誤差」としてまとめず、用途ごとに独立して定義する。

| ID | 用途 | 必要な定義 | 決定状態 |
|---|---|---|---|
| EPS-1 | downbeat–beat照合 | 単位、許容幅、比較演算、候補が複数のときの扱い | 未決 |
| EPS-2 | onset–slot境界分類 | 境界一致の優先規則、隣接slot候補が競合した場合の扱い | 未決 |
| EPS-3 | slot終端–`audioDuration`比較 | 完全slotとする終端条件、終端近傍の扱い | 未決 |
| EPS-4 | 境界重複・単調性判定 | 数値表現上の微小差と実際の重複を区別する方法 | 未決 |

### 3.1 必ず明文化すること
各EPS項目について、次の4点を一組で決める。
- 定数名と単位（秒、または別の明示単位）。
- 比較演算（`<`、`<=`、絶対差等）。
- 境界一致時の優先規則。
- 不一致・曖昧さが起きた場合の診断と新方式の適用可否。

既存`BEAT_EPS`をそのまま全用途に共有することは、実装の意図と利用箇所を確認するまで決めない。

### 3.2 C1との整合性
末尾領域は`[lastCompleteSlotEnd, audioDuration)`という半開区間（左端を含み右端を含まない区間）として定義されている。
- `lastCompleteSlotEnd`に一致するonsetは末尾領域側。
- `audioDuration`に一致するonsetは末尾領域内ではない。
- EPS処理によって上記の区間規則を暗黙に逆転させない。
- 音声終端と一致・超過するonsetの診断とlegacy側の扱いは、実装前に別途明記する。

## 4. 不規則小節の判定契約
### 4.1 既知の方針と未決の判定基準
**選択済み:** 不規則小節が1つでもあればチャート全体を既存方式へfallbackする。  
**未決:** 何を不規則小節と認定するか、特に短小節・pickup・downbeat欠落の区別。

| 条件 | 暫定的な扱い | 追加で必要な定義 |
|---|---|---|
| slotCountが0以下 | 構造異常として診断しfallback候補 | 0 slotが表現上許容される状況があるか |
| 境界対応が一意でない | 診断し、新方式を適用しない | 診断分類・コード名 |
| slotCountが標準値を超える | 不規則小節として扱う候補 | 標準slotCountの算出規則 |
| slotCountが標準値未満 | 自動的に異常としない | 正当な短小節との識別基準 |
| pickupかdownbeat欠落か判断不能 | #129補正を自動起動しない | #101内で診断・fallbackする条件 |
| onsetがどの区間にも一意に分類できない | 黙ってslot 0等へ割り当てない | 診断とfallbackの統一ルール |

標準slotCountを単純に`timeSignature.numerator * resolutionPerBeat`と置く場合でも、それは名目上の基準値であり、各小節の実測slotCountと同一とは限らない。6/8等の拍感をどう扱うかは、既存の拍子モデルの制約を確認してから決める。
