## 作業状態

- 対象Issue: GitHub Issue #99

## 完了したこと

| 変更 | 内容 | ファイル |
|---|---|---|
| 修正A | 置換欄（`aep-search-replace-input`）の`input`イベントへ`_refreshEditorView()`を追加。「置換」「全置換」ボタンの有効化条件（`canReplace`）は`search.replaceText`にも依存するが、従来は置換欄への入力だけでは再描画されず、UIへの反映が遅れていた | app.js |
| 修正B | 再描画時のフォーカス復元処理を、カーソル位置を常に文末へ固定する方式から、直前の実際のカーソル位置（`selectionStart`/`selectionEnd`）を記録し復元する方式へ変更。検索欄・置換欄の両方に適用 | app.js |

## 経緯（修正Bについて）

修正Aのみを実機検証した際、「置換欄の文字列の途中にカーソルを置いて入力すると、再描画のたびにカーソルが文末へ飛ぶ」という副作用が新たに発見された。原因は既存のフォーカス復元処理がカーソル位置を常に文末へ固定していたためで、置換欄を毎回再描画するようにした修正Aによってこの既存の潜在的な挙動が顕在化した。この副作用に対応するため修正Bを追加した。
