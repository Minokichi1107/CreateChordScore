# ローカルサーバーの待受範囲（UD-2）

決定：2026-11-05（ユーザー）。実装：`server.py`。

## 現在の動作

- `server.py` は **このPCからのみ**接続できる（`127.0.0.1:8767` で待受）。LAN内の別の端末（スマホなど）からは接続できない。
- 起動方法は従来どおり（`scripts/ChordScoreを起動.bat` または `python server.py`）。ブラウザで開くURLも従来どおり `http://localhost:8767/index.html`。
  - URLを `127.0.0.1` に変えない。ブラウザは `localhost` と `127.0.0.1` を別のサイトとして扱い、ライブラリや自動保存（localStorage / IndexedDB）が別物になって、保存済みの曲が消えたように見えるため。
- 追加の防御：`Host` が `localhost` / `127.0.0.1`（ポート8767）以外、または `Origin`（ブラウザが付ける送信元）が同じ範囲以外の要求は `403` で拒否する。閲覧中の他のWebサイトから、このPCのサーバー（解析データの読み書き）を呼ばれないようにするため。従来の `Access-Control-Allow-Origin: *`（CORS＝別オリジンからの利用許可）は廃止した。
- 認証機構はない。ローカル専用であることを前提にしている。

## LAN利用（別端末からの利用）は未実装・保留

認証なしのまま全インターフェースで待ち受ける設定は、**意図的に用意していない**（起動オプションも環境変数もない）。LANモードを作る場合は、先に次を設計・検証する必要がある。

- 認証・アクセス制御の方法
- CORS と `Host` / `Origin` 検査の許可範囲
- 静的ファイル配信の公開範囲（今はプロジェクトフォルダ全体が配信対象）
- `/save-analysis` など書き込みAPIのアクセス制御
- Windows上での起動方法と、利用者への警告
