# Chord Grid UI仕様書（v1.0）

## 1. 目的

本UIは以下を目的とする：

* 楽曲の時間構造の可視化
* chord change位置の明示
* beat単位での演奏理解
* 楽曲セクションの“雰囲気把握”（将来拡張）

※演奏再現やストローク再現は対象外

---

# 2. 基本構造

## 2.1 最小単位

* **1 beat = 1セル**

---

## 2.2 1小節構造

* timeSignatureに依存（通常4/4）
* 1 bar = N beats

```text
4/4の場合
| beat1 beat2 beat3 beat4 |
```

---

## 2.3 データ入力前提

UIは以下のみを信頼する：

* chordEvents（start / end / chord）
* beats（time array）
* timeSignature

---

# 3. 表示ルール

---

## 3.1 chord表示ルール

### 基本ルール

* chordは「開始beatにのみ表示」
* 継続beatは「・」で埋める

---

### 例

```text
| C  ・  ・  ・ | D  ・  Em ・ |
```

---

## 3.2 chord change表示

* chordが変わるbeatで明示表示

```text
C → D → Em
```

---

## 3.3 同一コード継続

```text
| C  ・  ・  ・ |
```

---

## 3.4 beat grid（補助線）

* 各beatは等間隔セル
* barごとに太枠または区切り線

---

# 4. Gridレイアウト仕様

## 4.1 横方向

* 時間軸（左 → 右）
* beat単位で固定幅

---

## 4.2 縦方向

* bar単位で改行

```text
Bar 1 | C  ・  ・  ・ |
Bar 2 | G  ・  Am ・ |
```

---

# 5. 表示構造（内部モデル）

UIは以下構造を想定する：

```json id="ui_model"
{
  "bars": [
    {
      "index": 1,
      "beats": [
        {
          "time": 0.39,
          "chord": "C",
          "isChange": true,
          "display": "C"
        },
        {
          "time": 0.87,
          "chord": "C",
          "isChange": false,
          "display": "・"
        }
      ]
    }
  ]
}
```

---

# 6. 色分けルール（ハイブリッド）

## 6.1 基本ルール

* bar単位で背景色を変える（軽い差分）

---

## 6.2 将来拡張（現時点は未実装）

* intro / verse / chorus / bridge
* ただし現時点では自動推定しない

---

# 7. chord change検出ルール

## 7.1 基本

* chordEventsのstartをchangeとする

---

## 7.2 補正（軽量）

* 同一コードが長時間続く場合はbeat再確認対象

---

# 8. 非対象（重要）

以下は今回スコープ外：

* ストローク表示
* セクション自動分類
* 音響ベース解析
* MIDI変換
* リアルタイム演奏生成

---

# 9. UI設計原則（重要）

## 9.1 UIは「理解装置」

* 演奏装置ではない
* 音楽理論装置でもない
* 時間構造の可視化装置

---

## 9.2 データ非依存

UIは以下に依存しない：

* chord数
* 曲構造
* セクション推定

---

## 9.3 派生データ原則

* Gridは常に再生成可能
* UIは状態を保持しない

---

# 10. まとめ（設計の核）

このUIの本質はこれです：

> chordEvents（事実）を
> beat（時間）に投影し
> Grid（視覚）に変換する
