## ① 最優先：Grid生成ロジック（コア）

やることは1つだけです：

> chordEvents + beats → beatGrid を生成する

---

### ここで作るもの

```json id="grid_core"
[
  {
    "bar": 1,
    "beats": [
      { "time": 0.39, "chord": "C", "isChange": true },
      { "time": 0.87, "chord": "C", "isChange": false },
      { "time": 1.31, "chord": "C", "isChange": false },
      { "time": 1.76, "chord": "C", "isChange": false }
    ]
  }
]
```

---

### 重要ポイント

* chordEventsを正として扱う
* beatsに投影する（ここが核心）
* Gridは派生データ

---

## ② chord継続補完ロジック

ChrodMiniの弱点を吸収する部分です。

やること：

* beatごとに「現在のコード」を保持
* chord change時のみ更新

---

### 擬似ロジック

```text id="logic1"
currentChord = null

for each beat:
    if beat.time >= nextChord.start:
        currentChord = nextChord.chord

    grid[beat] = currentChord
```

---

## ③ change検出フラグ付与

```text id="logic2"
if chord != previousChord:
    isChange = true
```

UIで必要になる部分。

---

## ④ bar構造の付与

ここで初めて：

* beats → bar grouping

```text id="bar"
4 beats = 1 bar（4/4の場合）
```

---

## ⑤ UI用データ完成

最終的に：

* grid
* bar
* change
* chord

が揃う
